Para rodar o "Super Ultra Mega Buscador" em sua máquina local, siga os passos abaixo.

### Passos para Execução

1.  **Clone o repositório**

2.  **Crie o ambiente virtual (venv):**
    *(Este comando cria uma pasta `venv` para isolar as dependências do projeto)*
    ```bash
    python -m venv venv
    ```

3.  **Ative o ambiente virtual:**
    * **No Windows (PowerShell/CMD):**
        ```powershell
        .\venv\Scripts\activate
        ```
    * **No macOS/Linux:**
        ```bash
        source venv/bin/activate
        ```

4.  **Instale as dependências que forem necessárias**


5.  **Execute a aplicação:**
    ```bash
    python front.py
    ```

6.  **Acesse o buscador pelo servidor que for indicado ao executar**


### Para parar o servidor

No terminal onde o `python front.py` está rodando, pressione `Ctrl + C`.
